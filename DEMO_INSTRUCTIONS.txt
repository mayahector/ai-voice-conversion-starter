DEMO VIDEO INSTRUCTIONS
========================

This document provides step-by-step instructions for creating a comprehensive demo video
of the Real-Time AI Voice Conversation application.

PREPARATION
-----------

Before recording:
1. Ensure both backend and frontend are running without errors
2. Test microphone and audio output
3. Clear browser cache and close unnecessary tabs
4. Use a quiet environment for recording
5. Prepare a script of what you'll say to the AI
6. Have your code editor ready for code walkthrough


PART 1: INTRODUCTION (30 seconds)
----------------------------------

1. Show the project folder structure in Finder/Explorer
   - Highlight: frontend/, backend/, README.md, AI_PROMPTS.md

2. Briefly explain the tech stack:
   - "This is a real-time AI voice conversation app"
   - "Built with Next.js, Express, LiveKit, and OpenAI"
   - "Enables natural voice conversations with AI"


PART 2: RUNNING THE PROJECT (1 minute)
---------------------------------------

1. Open Terminal/Command Prompt

2. Split screen to show two terminal windows

3. Terminal 1 - Start Backend:
   $ cd backend
   $ npm run dev
   
   - Show the startup logs:
     ✅ Server running on http://localhost:3001
     ✅ LiveKit URL configured
     ✅ OpenAI API configured

4. Terminal 2 - Start Frontend:
   $ cd frontend
   $ npm run dev
   
   - Show the startup logs:
     ▲ Next.js running on http://localhost:3000

5. Open browser to http://localhost:3000


PART 3: LIVE DEMONSTRATION (2-3 minutes)
-----------------------------------------

1. Show the landing page:
   - Point out the clean, modern UI
   - Highlight the status indicators (disconnected, mic inactive)
   - Show the instructions panel

2. Click "Start Conversation"
   - Show the browser microphone permission prompt
   - Click "Allow"
   - Show connection status changing: Connecting → Connected
   - Show microphone status changing to "Active"

3. First interaction:
   - Say: "Hello! Can you hear me?"
   - Wait for AI response
   - Show transcript appearing in real-time:
     * Your message (blue bubble, right side)
     * AI response (gray bubble, left side)
   - Let the AI voice play audibly

4. Second interaction:
   - Say: "Tell me a fun fact about space"
   - Show transcript updating
   - Demonstrate AI voice response

5. Third interaction:
   - Say: "What's the weather like on Mars?"
   - Show the full conversation flow

6. Demonstrate controls:
   - Click "Mute Microphone" button
   - Show mic status changing to "Inactive"
   - Click "Unmute Microphone"
   - Show mic status changing back to "Active"

7. End conversation:
   - Click "End Conversation"
   - Show status changing to "Disconnected"
   - Show transcript is preserved

     * textToSpeech() - TTS API
   - Show the sequential flow

4. Show backend/src/routes/ai.ts:
   - Explain the /api/ai/process endpoint
   - Show how audio data flows through the system

Frontend Code:

5. Show frontend/hooks/useLiveKit.ts:
   - Explain the custom React hook
   - Show connection logic (connect function)
   - Highlight audio processing setup
   - Show transcript state management

6. Show frontend/components/ConversationRoom.tsx:
   - Explain the main UI component
   - Show button handlers
   - Highlight state management

7. Show frontend/components/StatusIndicator.tsx:
   - Explain real-time status display
   - Show animated indicators

8. Show frontend/components/TranscriptDisplay.tsx:
   - Explain chat-style transcript UI
   - Show auto-scroll functionality

PART 6: AI PROCESSING FLOW (1 minute)
--------------------------------------

1. Switch to backend terminal

2. Show backend logs during a conversation:
   - "Transcription: [user speech]"
   - "AI Response: [generated text]"

3. Explain the flow:
   - Audio received from frontend
   - Sent to OpenAI Whisper for transcription
   - Transcription sent to GPT-4 for response
   - Response sent to TTS for voice synthesis
   - Audio returned to frontend

RECORDING TIPS
--------------

✅ Use screen recording software (OBS, QuickTime, etc.)
✅ Record at 1080p or higher resolution
✅ Enable microphone for narration
✅ Speak clearly and at moderate pace
✅ Pause between sections for editing
✅ Show actual functionality, not just code
✅ Demonstrate error handling (optional: try disconnecting internet)
✅ Keep total video under 10 minutes

❌ Don't rush through sections
❌ Don't show actual API keys or secrets
❌ Don't skip the live demo
❌ Don't forget to show the AI responding
